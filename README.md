# Dialtone

A phone book for your coding agents: voice-call any Claude Code or Codex session on your Mac.

Download the latest build for Apple-silicon Macs from
[Releases](../../releases/latest). The disk image is password-protected; ask the person who sent
you here for the password.

You need Claude Code or Codex installed and signed in, and an ElevenLabs API key with access to
ElevenLabs Agents, which you paste into Dialtone's Settings on first launch.
